This browser can't talk to USB serial ports. Use Chrome or Edge on a desktop computer. Open this page over HTTPS to flash.
  1. Connect the robot's ESP32 to this computer with a USB cable (install the CP210x / CH340 driver if no port shows up).
  2. Pick the robot model and press Connect and install, then choose the serial port.
  3. Leave Erase device unchecked to keep the servo trims and other settings. Erase only for a clean install.
  4. Some boards need the BOOT button held while the upload starts.

The firmware is built from the main branch. The robot starts its own WiFi access point with the SSID and password from config_wifi.example.h; build it yourself with config_wifi.h for your own credentials.
